# Contributor guidance

See [CLAUDE.md](CLAUDE.md) for project conventions.

Edit documentation in `src_docs/md/` and configure fly-january 0.1.1 in
`src_docs/mkdocs.yml`. Keep `extra.fly.chrome: none` for this unofficial site.
Run `./build.sh docs` to rebuild the tracked `docs/` directory in strict mode.
